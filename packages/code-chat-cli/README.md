# code-chat-cli

`code-chat-cli` は, ローカルリポジトリのコードベースを解析し, コマンドラインから直接対話・質問ができる CLI ツールです. 

---

## 主な機能

* **リポジトリのインデックス作成**: コードベースをベクトルデータベース (ChromaDB) にインデックス化します.
* **インタラクティブチャット**: リポジトリのコンテキストを参照しながら RAG (Retrieval-Augmented Generation) によるコード解説や質問応答を行います.
* **ストリーミング出力**: LLM の回答をリアルタイムで端末上にストリーミング表示します.

---

## インストール

`uv` を使用して依存関係をセットアップします.

```bash
uv sync

```

---

## 使い方

### 1. リポジトリのインデックスを作成する

対象のリポジトリを解析し, ローカルデータベース (`./.chroma_db`) にベクターデータを作成します.

```bash
uv run code-chat index /path/to/your/repository

```

**実行例:**

```text
Index completed: 128 chunks added.

```

---

### 2. コードベースについて質問する (インタラクティブモード)

インデックス作成後, インタラクティブなチャットセッションを開始します.

```bash
uv run code-chat ask

```

**実行例:**

```text
質問を入力してください (Ctrl+C または 'exit' で終了):
> このプロジェクトのメイン処理のエントリポイントはどこですか？

コンテキストを参照して回答中...
このプロジェクトのエントリポイントは `packages/code-chat-cli/src/code_chat_cli/chat.py` の `main()` 関数です.

```

---

### 3. ワンライナーで質問する

1 回の質問と回答の出力のみを行う場合は, 引数に直接質問文を指定します.

```bash
uv run code-chat ask "CodeRagService の役割は何ですか？"

```

---

## コマンド一覧

| コマンド | 説明 |
| --- | --- |
| `code-chat index <repo_path>` | 指定したリポジトリパスのコードをインデックス化します. |
| `code-chat ask [question]` | インデックスを参照して質問に回答します (引数なしで対話モード). |

---

## 開発・テスト
